# Technology icons

Icons identify the technologies used in the profile's projects.

- React, TypeScript, Vite, CSS, HTML, JavaScript, Tailwind CSS, GitHub Actions and Next.js: [Skill Icons](https://github.com/tandpfun/skill-icons), MIT. See [LICENSE-skill-icons.txt](LICENSE-skill-icons.txt).
- React Router, Playwright and Motion: [SVGL](https://github.com/pheralb/svgl), MIT. See [LICENSE-svgl.txt](LICENSE-svgl.txt).
- GSAP and Lenis: official apple-touch icons.
- Vinext: official site favicon, extracted at 64×64 as PNG. The site uses the Cloudflare mark; the README tooltip identifies Vinext and its Next.js App Router API compatibility.

Brand names and marks belong to their respective owners and do not imply affiliation or endorsement.
